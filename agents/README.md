# agents

Setup for the CREAO AI agents. These are configuration and instructions, not application code.

| Folder | Purpose |
|---|---|
| `personal-agent/` | Instructions and profile template for each researcher's personal agent |
| `hub-agent/` | Instructions for the central research intelligence agent |
| `skills/` | CREAO custom skills, e.g. diagnostic playbooks ("how we debug instability") |
| `reference-files/` | Baselines, config templates and checklists the agents read on every run |
