# shared

Definitions used by both `frontend/` and `backend/`, so the two always agree.

| Folder | Purpose |
|---|---|
| `schemas/` | Core entities (Project, Researcher, Experiment, Run, Artifact, Observation, Hypothesis, Finding, Failure record, Decision, Lesson learned) and API request/response shapes |
| `constants/` | Fixed value lists: epistemic statuses, user roles, alert routing options, autonomy levels |
